User Import/Export Instructions

Use an .xlsx file. The first row must be the header row. Column order matters.

  • Import Columns:
    • name (Required): User's full name.
    • email (Required): User's unique email address. Existing users are matched by email for updates.
    • password (Required for new users): Set initial password. Leave blank or omit column when updating existing users to keep their current password.
    • role (Required): Must be one of user, judge, or admin.
    • judge_request_pending (Optional): Set to TRUE to mark as a pending judge request, otherwise FALSE or omit (defaults to False).
  • Export: Creates an .xlsx file with all users, including their id, name, email, role, and judge_request_pending status.

Project Import/Export Instructions

Use an .xlsx file. The first row must be the header row. Column order matters.

  • Import Columns:
    • project_name (Required): The name of the project.
    • group_id (Required): The numeric ID of the associated group. The group must already exist in the system.
    • description (Optional): A description of the project.
  • Export: Creates an .xlsx file with all projects, including their project_id, project_name, group_id, and description. Assigned judges are not included in this export file (use the UI to manage assignments).

Note on Judge Assignments: Judge assignments are managed via the "Assign Judges" button in the actions menu for each project and are not part of the standard import/export.

Score View and Export Instructions

This table displays the average score for each project within each recorded category. Columns are dynamically generated based on the categories found in the score data. Empty cells indicate no score was given in that category for that project.

  • Export: The "Export Individual Scores" button generates an .xlsx file containing all individual score entries with detailed information (score_id, category, score_given, project_id, judge_id, timestamp, etc.). This is different from the aggregated view shown in the table below.
  • Adding Scores: Use the "Add Score Entry" button to add individual scores via the modal form. These entries contribute to the average scores shown in this table after the page refreshes or data is re-fetched.
  • Managing Scores: To edit or delete individual score entries, create a custom table section filtered for 'Scores (Individual Entries)'. Actions like Edit/Delete are available in those custom tables, not in this aggregated view.
